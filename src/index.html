Welcome to my JavaScript Atari 2600 emulator!

This is a pet project I built for fun while learning how the original console worked; read more about building this emulator in my blog post.

Currently supported games include Bowling, Combat, Frogger, Moon Patrol, Ms. Pacman, Pong Sports, Tennis, Tic Tac Toe 3D, and Super Breakout. The emulator is a work in progress - I'm planning to add audio and additional games over time.

Want to try your own games? Use the upload button next to the ROM selector to load your own Atari 2600 ROMs. There are many complete Atari 2600 ROM archives available online, but I won't link to them here due to unclear copyright status. Please ensure you own any games you're emulating.
